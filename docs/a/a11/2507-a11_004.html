科學可解釋佛法嗎?

各位菩薩：

阿彌陀佛！

我們今天要講的子題是：科學可解釋佛法嗎？

在佛經上有說，這是屬於阿含部的經典，叫《恆水經》。《恆水經》上面有提到說：世間的一切的經法，世間一切，就是真正可以流傳、利益世間的，實際上都是從佛法而來的，所以佛法也包含世間法。包括這些外學，就是包括醫方明，還有世間法的因明，這些全部都是佛法所包含的。

「明」就是指徹底明了這些世間法的道理，其實不論是卜卦、八字、風水，實際上是菩薩無不明了。這是入地菩薩於五地菩薩位所應當成滿的功德，五地菩薩對於這世間，他自知他瞭解得不多，所以他會啟動他的意生身，去無量無邊的世界，來瞭解世間一切有情的作息，一切世間有情的許許多多的根器。他是透過這個方式來瞭解他們在作什麼？他們會的是什麼？然後有沒有一些工巧的一些技藝，這些諸明（諸明就是明白這個事情的道理）需要他來學習，所以他一切究竟了知。所以佛法是反過來可以來解釋科學的，因為必須要如此，因為他要走過第二大阿僧祇劫的修行位，他就必須要會一切世間法的科學。所以不只是醫學，然後乃至於工巧明的科學，他全部都要會。

所以這個是菩薩的有學的地方，這菩薩的學處。也就是說菩薩的內學，聽起來好像是要說這些布施、持戒然後忍辱、然後精進，乃至於禪定，最後到般若，乃至於說十地菩薩的時候，繼續延伸，然後把六度波羅蜜成為十度波羅蜜。可是除了這些內學以外，還是有外學，因為這些內外兼學的情況，就能夠讓眾生明了菩薩的威德力。而且可以透過這些學處，明了這些學處，你就可以來醫病，你就可以來製作電腦，你就透過科技昌明，拿來宣揚佛法。所以科學一樣可以來輔助，所以佛法中要明了科學，就像是我們現在透過這種錄影的設備，可以讓這影像繼續地流傳下去，這樣的話，就可以利益到更多的有情，讓他們知道佛陀所說的道理、所說的真義是什麼！

提到這錄影設備，我們就來解釋一下這世間法，科學的極限是什麼。世間人他們做一種叫作隨機機器，隨機機器它出現一個或叫0、或叫1，這屬於二進位。二進位的話最單純了，結果不是這邊就是那邊、0或1、或是左邊右邊，然後這個隨機機器它很有趣，因為是隨機的，所以大致上，兩邊出現的比率就會一半一半。譬如說一個時間裡面，它出現0 0 0 0，然後等一下又出現1 1 1，等一下又0 1 0 1 0 1，0 0 1等等，最後統計起來，0和1的數目差不多。但是科學家不能解釋的事情在後面，他們第一個不能解釋的事情是：如果說你今天你是男人，因為男人和女人有差別，我們就先說一下男人部分。你去想：「希望1比較多」，就很奇特喔！它的平均數就變化了，會超過百分之五十，而且這是幾乎試起來大都如此，就不會是五十五十。也就是說，我的心識是可以影響到這個隨機的機器，不是說你在旁邊大吼大叫，或是說去搖這個機器，不是喔！你可以放輕鬆坐在那裡用想的，希望1比較多這樣就會影響了。那女人的話也一樣，但女人更特別，科學家發現一件事情，女人最好心亂一點效果會最好。這句話怎麼說呢？就是說，她的心識也是可以影響到機器喔！這已經是科學不能解釋；而且最好這個女子做一些其他事情，就是說一心多用的意思，這樣的話，這機器就會動得更複雜，就會更顯著，不會跟百分之五十只差一點點。

那你想：「怎麼會這樣呢？」所以說，心識這個地方，科學可以解釋嗎？這變成死棋了，因為科學不能夠解釋心識的種種行為，可是心識卻可以透過科學的實驗，而顯示在科學的一切記錄上。那怎麼辦呢？所以科學確實有它的極限。

但我們今天說的還不是這樣，我們要讓大家來看一看心識的力量到底有多大？因為科學家又做了一件事情，他今天先把錄音帶錄好，錄音帶是沒有人干擾的喔！然後這錄音帶沒有人干擾的情況下，錄好以後把它拷貝。我們現在都知道拷貝就是複製，就是說你把這錄音帶再錄到別的地方去，然後實際上兩個內容是一模一樣的。好！既然一模一樣，然後過幾天就郵寄的或其他方式，寄到另外一個人的那裡去。好！那他收到了，譬如說某甲收到了，或者A收到了，某甲或A這時候就開始聽錄音帶，然後他當然也可以聽左耳右耳這種聲音，因為可以把1變成是左耳，0變成是右耳。那他也可以有記錄器，他也可以不用聽，就是只是放這錄音帶，反正會有機器幫他記錄，最後統計這數據出來，看看是左邊比較多還是右邊比較多？

結果你知道發生什麼事情嗎？更奇怪的事情發生了，雖然這些錄音帶是當初就錄好的，左邊和右邊聲道應該是百分之五十對百分之五十。可是很遺憾的不是這樣，這個實驗怎麼試都是如此，只要你在這個播放的時候，開始期望1比較多，就會1比較多；0比較多，就會0比較多。也就是說左耳右耳的聲音，它們嘟嘟或是嘀嘀會不一樣。那透過這樣的話，就更沒辦法理解了。也就是說，錄音帶不是早就錄好了嗎？是幾天後才寄到這個人手裡啊！那錄的那個時候就已經能夠，機器就預知會有一個傢伙來聽錄音帶嗎？所以它這個實驗還有做喔！理論上是說，你可以不用去影響它，不過不管怎麼做，不管他有沒有做這個實驗，單單是0，然後希望比較多，或是1希望比較多，它就如你意思來作。

不過雖然如此，這個實驗還有因為科學家他們這個報告裡面沒有說得更多，不過他們有提到：當第一個人聽過之後，譬如說第一個人，他希望1比較多，左耳比較多，左邊耳朵聽到嘀會比較多的時候呢，最後再請第二個人來聽是無效的。也就是說你拷貝同時送給乙、送給甲，然後甲已經聽完了嘛！所以就決定下來，這時候乙你再怎麼樣努力，也沒辦法把0變成比較多。好，科學家有哪一位可以來解釋這個事情呢，沒有！現在不會有，以後也不會有，除非他學佛。

那你說這麼簡單的實驗，我也可以來做。是沒有錯，只要你用任何的一個自己產生儀器，或是說你用一個電腦程式寫，讓它固定會在只要你能夠有一個統計值，這個實驗是不會變的，因為它牽涉到法界的基本的本質不變，也就是說這裡面觀察者，他是決定現象的人。那你說：「這句話是什麼意思？」也就是說觀察者他可以決定法界的一些行為狀態，譬如錄音帶，當你不決定它0或1是可以的，因為又沒有人關心它，沒有人去注意它，等到你去關心它、注意它，你就把它的行相刻劃下來，它固定下來，就會變成固定是0比較多或1比較多，按照你期望來走。那如果今天你沒有這個心識，眾人沒有這個心識去注意它，那當然就不會啦！所以我們今天要說的是：科學不能離於這個法，離於這個心識之法。

那我們再說一些科學的實驗，因為這都是很基本的實驗，不是一般人聽了不太會懂的實驗。譬如說，有一種它會產生分子分裂，它左右兩邊送出兩顆微中子。這兩顆微中子，因為它們有電量，或是它們會被磁場所干擾，所以它們在另外一側，就是譬如說，你右邊那一顆微中子打出去，他就在那一邊放一個電磁場，這樣這微中子碰到電磁場它就轉彎，然後就轉彎嘛！對啊！這樣很好，可是接下來的事情，科學家就覺得大大不好了。為什麼呢？因為左邊那一個微中子，沒有放任何的電磁場，它也轉彎了，而且它轉彎的方向是跟右邊這個是顛倒的。也就是說這兩顆微中子，彷如有情心識相通，實際上它們是無情，它們只是物體，它們不可能有什麼心識相通的道理啊！可是它們兩個就像是透過無遠弗屆的距離，它們就通報訊息：我轉右那你呢？可要等一下向左轉喔！這樣子，所以這有哪一位科學家可以解釋嗎？沒有！答案還是一樣，以前沒有，以後也不會有，除非他學佛。

也就是說這個法界中啊，你的心識的力量確實像是如來所說的，就是能夠出生一切法，讓這些法成為這世間的一些軌範、定則，因此它可以被科學來測量。可是因為科學的這些研究，他沒有去熏習佛法，他不相信心識有這樣的威力，有這樣的力量。所以他沒有辦法來解釋這個道理，因為他沒有辦法分析這個超越光速的這樣的速度，超越光速的極限，到底是怎樣來溝通這個訊息。現在科學家想要利用這個方式，來作遠距離的通訊，因為你遠距離的話，如果看到這邊的變化，然後另外一邊一定是一個相反的一個變化。法國的科學家曾經用光纖，因為光纖就比實驗室的距離，雲霧室或等等的距離要來得長，可是不論他們做了是多麼長，長達多少公里，這兩顆微中子還是會選擇對稱的路徑，不管它們跑多遠，它們宛如心靈相通。

實際上這不是什麼心靈相通，就是說如來藏讓法界的一切原理都變成如此。包括說啊，科學家所覺得最為棘手的光波的干涉的這個問題，他說這個光應該是一顆一顆粒子，然後它不應該是波。可是後來干涉的現象出現以後，大家知道這應該是波，不是一顆一顆粒子而已，可是光粒子又可以被實驗出來，這樣就很納悶了！所謂光波的干涉是怎麼樣呢？就是你在一個屏幕上看到光會形成加強或是減弱的這樣的特性，那光從哪邊照過來，你就挖兩個小孔，從外部送過來，那光可以透過A孔，也可以透過B孔兩個孔過來。那如果是現在科學，因為它太厲害了，它一次只可以打出，可以做到一次打出一顆粒子，光粒子喔！透過一顆光粒子射出來了，然後這光粒子到達這兩個洞之前，或是它會選擇路徑，它自然就會趕快變成波，所以很納悶吧！科學家只好說這是光的二向性，因為它有兩種特性，可是它為什麼這麼清楚知道，它那時候它會變化，科學家老實說也不知道。

可是我們透過佛法知道，佛法告訴我們如來藏出生一切萬法，所以一切萬法的軌則就是需要菩薩在無量無邊的世界，即使有的世界它超過光速，你一樣能夠解釋。就像是我們要到極樂世界往生一樣，你要經過十萬億的佛土，然後中間，你的心識等等要超越這個光速，但是這一切一切的威德力，一切一切的功德力，一切的作用，都還是來自於如來藏。乃至於醫學，他們也有困惑，這就牽涉到叫水的記憶。

這個實驗算是醫學實驗、醫療實驗，或算是醫學研究，也可以算是科學。它實驗也很簡單，它怎麼作呢？他就將一個有效的這個藥劑，用十分之一放在水中，也就說藥劑的比例和水比例是1比9。這樣作出來就十分之一嘛！稀釋變十個百分比，然後再繼續稀釋，因為有一位醫療人員，他不小心作錯實驗，所以我們就透過這作錯實驗，來知道這件事情。他繼續把這個十分之一，繼續稀釋一次，就變成百分之一了；百分之一再稀釋一次，就變成千分之一、萬分之一。然後一直稀釋下去，他最後稀釋到，裡面絕對沒有機會還有一個藥劑的水分子，我們講是水分子的存在，他已經這樣一直作，因為你作了幾百次以後，幾乎一顆水分子都不應該存在，應該都幾乎是水了。可是這樣的水一樣有藥效，所以世間的人更難以想像，為什麼它會有藥效呢？明明已經都是水了，已經不是那個藥劑了，為什麼還會有藥效？

是啊！因為水這種大種性自性，是來自於誰的體性？就是如來藏的體性啊！地水火風這四種物質的體性，就是來自於如來藏，可以成就世間的一切物質的體性，這個就是由如來藏所成就。因此水的特性，就是可以具有這樣把承載著你所要提的這種藥療、藥性，這樣承載過來，只是說這種承載的話，你還是必須要透過親證，瞭解這佛法的實際，你才能夠理解。

所以我們看到說，這法界中有許許多多的科學家所不能夠清楚的，本質的問題它很難以被理解，但是可以被觀察。那如果說還有許許多多的，我們幾乎是不可觀察的呢？包括說明心見性，譬如說世間的人，不說明心好了，說見性，許許多多的人就不能理解，包括說我們要親近善知識，最後有因緣才能夠見性。像講堂裡面也只有少數的人可以見性，像末學對這個法，也是處於不可觀察，這都需要我們在這甚深的佛法中繼續地前進。

同樣的我們所知道的這個明心，對於眾生來說也是不可觀察，然而這些都是可以來解釋，可以透過語言文字來解釋，也可以透過許許多多的證驗是真有其事的；這就像是如人飲水，你就可以知道到底是冷的還是熱的。所以我們今天看待這些的法，不管是現在存在的法，還是未來存在的法，科學它的極限需要透過佛法昌明來加以解釋，才能夠將物質與心識的法，能夠完美地來作詮釋。像是有的人他有心電感應，他可以知道突然有一件事情發生了，譬如說這比較多的話，通常是跟他生死有關！有的人他要上飛機之前，前一天他就作夢，夢見飛機失事，因此他非常擔心，最後就決定他去退掉飛機票或是不上飛機等等，後來那架飛機很不幸地就失事了。這樣的感應為什麼會有呢？同樣的這也是如來藏的種種的功能體性，因為如來藏祂本身沒有三世的間隔，對於祂過去、現在與未來，祂都是可以產生的。

那透過另外一個，要實踐心電感應的第七識，第七識在佛典裡面來說，祂可以默容，默容就是祂可以接受三世一切諸法。所以過去現在與未來，祂一樣可以來接觸，所以就會有這樣的心電感應。乃至於人死之前，許多人會現起業鏡，業鏡就是說把他這一輩子所發生的事情全部現出來，當然是最重要一些事情，從小到大喔！這樣現在他眼前。這業鏡不只是東方人可以體驗的，西方人也體驗，甚至他們因為這樣來寫的一些關於臨死現象的這些書籍。所以我們來說，佛法是可以來解釋世間一切法，當然也可以來解釋科學。

好，我們今天就講到這裡。

阿彌陀佛！
