知恩報恩(一)

各位菩薩：阿彌陀佛！

歡迎您收看正覺教團電視弘法節目，目前演述的主題，主要是以 蕭平實導師著作《涅槃》為藍本，略說對於想要實證解脫果的人而言，得瞭解佛法中的「法」與「次法」的關聯性。今天我們將接續前一集，正嫺老師所講述的內容，繼續為大家介紹「次法」的最基本條件——布施之論，也就是布施的因果正理。

我們學佛是嚮往佛法的解脫與成佛的智慧，這些智慧可以統稱為「法」。那如何是次法呢？次法就是支撐佛子們修「法」的道路，能快速圓滿成就。換一個大家比較熟悉的說法，「法」相當於佛法智慧，而「次法」就是福德；也就是修行人在實證佛法前，所必須具備的基本條件。在佛法中，最常以解脫生死到彼岸作譬喻，從有生死的此岸，到解脫的彼岸；福德就是水，智慧就像是船筏，運載船筏之水夠深夠廣，才能夠讓船平安地渡過險灘，從此岸順利抵達解脫的彼岸。所謂的「布施之論」是說布施的因果，屬於行十善的範圍。布施的人在未來世，可以獲得世間資財上的福德；由於已經具有這個福德，可以用來迴向佛法上的實證，成為實證聲聞菩提、緣覺菩提、佛菩提等三乘菩提的資糧。

這樣理解之後，我們要如何修集福德呢？經典中，佛世尊曾有相關的開示：福德屬於眾生。也就是說，福德是從眾生那裡獲得。請注意喔！佛法中所說的福德，不僅僅侷限於物質財富。讓我們恭讀 佛陀在《大方廣佛華嚴經》中的開示：【譬如曠野沙磧之中有大樹王，若根得水，枝葉、華果悉皆繁茂；生死曠野菩提樹王，亦復如是。一切眾生而為樹根，諸佛菩薩而為華果，以大悲水饒益眾生，則能成就諸佛菩薩智慧華果。】（《大方廣佛華嚴經》卷40）經文中說，譬如在曠野沙漠之中，有一棵長得很高大的樹王，倘若大樹的根部得到充裕的水分，其枝葉以及開出來的花，結出來的果實，都能夠很繁密茂盛；就是像這樣子，譬喻在生死輪轉的曠野中，一棵能夠成就菩提的大樹王，它的樹根部分屬於一切有情眾生，而所有的諸佛以及菩薩屬於花朵以及果實的部分。當發起菩提心的菩薩們在行菩薩道時，能不斷地以大悲水滋潤樹根——也就是饒益眾生，最終大樹就能開出繁茂的花朵與結出豐碩的果實，換言之就是成就諸佛菩薩的智慧花果。

這段經文譬喻有情眾生，在不停息的生死流轉貧瘠曠野之中，原本都具有成就菩提的本質與功德，若有好因緣，經由熏習佛法而發起菩薩性，未來就能是成就菩提的大樹王。它的樹根部分，譬喻為一切的有情眾生，它的花及果實的部分，比方為修行成就的佛以及菩薩；在無盡的生死流轉中，若有菩薩們不忍眾生苦，發起救度眾生的菩提心願，在一世又一世與眾生互為眷屬的修行過程中，以布施、忍辱之心，以持戒、精進之行等各種方式，饒益引導周邊的有緣人、拔苦與樂，這就是以大悲水滋潤眾生的意思。也等同樹根得到充分的灌溉，枝葉花果自然能茂密，這就是說明因為有菩薩發起菩提心，經由饒益眾生之後，而能成就無上正等正覺。

所以經文中又說：【是故菩提屬於眾生，若無眾生，一切菩薩終不能成無上正覺。】（《大方廣佛華嚴經》卷40）經文的意思是說，菩提是屬於眾生的，如果沒有眾生，一切菩薩終究不能圓滿成就無上正等正覺。也就是說，諸佛菩薩能圓成無上的智慧佛果，是經由一世又一世不間斷地利樂有情，譬喻以大悲水潤澤樹根，從中落實六度波羅蜜，一一實踐、經歷，以正知見為前導，以種種善巧方便解決困境，這都是成就佛菩提所必須經歷的過程，逐次圓滿種種智慧，才能開出生死曠野中菩提樹王的花果。所以說菩提屬於眾生，必須與眾生互動，從挫折中吸取經驗，獲得解決辦法，結下善緣，並善巧地將眾生帶入佛法，才能成就佛菩提，這就等同福德是屬於眾生。

各位菩薩！佛法不是思想的理論玄學，而是要付諸實行，可以親自體驗，證得而有受用。讓我們將經文內容，落實於日常的行住坐臥，與眾生互動之中：我們環顧周遭複雜的人際關係，處理不完的疑難雜症，偏偏都要我們去服務，去解決問題。從佛法的角度來說，如果一個發心的菩薩，在世間所扮演的角色，連世俗雜務都無法勝任，如何能誇口想要饒益一切有情呢？我們並不是活在無煩憂的烏托邦，尤其是父母親、長輩們帶孩子的生活經驗，每次突發的棘手狀況，都是能激發智慧的專案，這也是次法，因為護衛著下一代有情生命的平安成長。所以諸佛都是在人間示現成佛，不但十八界具足，尤其在五濁惡世，千奇百怪的善行、惡事，各類種子隨時可以觸發，能快速累積圓滿一切種子的智慧。

我先舉出自己遇到的案例：前幾天看見報導，有人在捷運上讓座，他才站起來，位子立即就被另一個小伙子霸佔，讓座的好意沒有達成，引發網友爭辯。接著，竟然看見有人留言：「有空位，任誰都可以坐下呀！」當時心中嘀咕著，真是荒謬！過兩天自己在捷運裡，看見左斜前方約三、五步的距離，站著一位長者，我本能地站起來要向他走去，當左腳一大步跨前時，一個念頭突然閃過，於是就把已經舉起的右後腳，再將腳尖貼回座位前的地上，止住雙腳不再向前離開位置，開著腳身體向前傾。很明顯，這不是正常的姿勢。開口正在招呼老人的時候，眼見右邊有一位年輕人，握著手機很快步走過來。我立即將重心退回右腳尖，舉起右臂張開五指，用手掌擋住他，同時微笑搖頭，很清楚地說：「欸！這位置是要讓給那位老先生的。」對方立即止步，很有風度地點頭微笑。下捷運時，很慶幸自己前兩天瞄見無足輕重的荒謬事故，卻讓自己避免了很可能引發的煩惱。這也是次法呀，與眾生互動結了善緣，沒有惡言相向！

各位菩薩！我們常說眾生、眾生，經典中記載著諸佛菩薩度了無量百千萬億數不盡的眾生，這麼多眾生，我們如何能結這麼多眾生緣呢？實際上，我們也已經結了數不盡的眾生緣，每一世的六親眷屬、同事、鄰居，最親近的以五個人計算。上一世，再上一世，無量的上一世，還有無量的未來世，都乘以五人，三大阿僧祇劫行菩薩道，身邊共有多少的眾生呢？差別在於我們與他們種下的是善緣還是惡緣，可別變成討債的冤親債主，因為再辛苦也是屬於我們要度的眾生喔！

我們再分享另一段相關的經典內容，有一回阿難尊者入王舍城托缽，一位六識外道向尊者挑戰說：「你的師父瞿曇啊！只有空名，沒有行善的實質，實際上是個惡人。祂出離皇宮，讓父王憂惱，棄捨妻子出家不顧，是個不孝，又不知恩的人。」阿難尊者聽了之後無言以對，回去請問 世尊：佛法中還有重視孝養父母這件事嗎？世尊藉此因緣，微笑放光到十方世界的佛淨土，吸引那邊無量百千萬億的諸菩薩眾，好奇地詢問他們的佛陀，是何等因緣而有這種異相？他方世界的諸佛世尊，都同樣讚歎 牟尼世尊，願在娑婆世界眾生具足煩惱、五逆十惡之中成佛，利益大眾。今時 牟尼佛放光，是為了開示《大方便佛報恩經》，以饒益一切眾生的緣故；也為了拔除眾生偏邪、疑惑的愚癡毒箭，尤其是要讓眾生懂得孝養父母的緣故。當時諸佛都鼓勵該佛土的菩薩眾等，前往娑婆聽聞 釋迦世尊開演《大方便佛報恩經》，並且還囑咐那些菩薩眾，絕不能懷有輕慢心聽 佛說法。

世尊於經文中如是說：【如來本於生死中時，於如是等微塵數不思議形類一切眾生中，具足受身；以受身故，一切眾生亦曾為如來父母，如來亦曾為一切眾生而作父母。】（《大方便佛報恩經》卷1）經文意思是說，當初 如來還在菩薩位修行時，於流轉生死中，在如同微塵數這麼多不可數、不可想像的各種形狀、種類眾生中，一一受生全都經歷過。以這樣的因緣，與許多眾生結過緣，可以說一切眾生都曾作過 如來的父母，而 如來也曾經作為一切眾生的父母。

從經文中可以得知：因為長劫流轉生死，在無終止的排列組合中，有情眾生都是生活在互為眷屬的因緣中。而 佛陀是很早就已經發起菩提心的菩薩，每一世為了感念父母之恩，若有因緣，常常實踐難行的苦行，難捨而能捨，自己的身肢軀體、身邊的兒女妻子、城國王位等等，一切都能捨離以供給父母之需。持續經歷長劫的調柔心性，之後再有因緣聽聞正法，能夠如所聽聞的法理付諸實行，心不懈怠勇猛精進，然而內心絲毫沒有倦怠疲憊的念頭。

經文中還說：【為孝養父母，知恩報恩故，今得速成阿耨多羅三藐三菩提。以是緣故，一切眾生能令如來滿足本願故。是以當知一切眾生於佛有重恩，有重恩故，如來不捨眾生。】（《大方便佛報恩經》卷1）經文的意思是說，過去無量世為了孝養父母，懂得知恩報恩而親力親為的緣故，今日得以快速成就無上正等正覺。由於這樣的因緣，一切眾生能讓 如來圓滿當初於菩薩位所發的本願，所以應當知道一切眾生於 佛有重恩，有重恩的緣故，如來不捨於眾生啊！

從經文中得知：當初 佛陀能夠「知恩報恩」的緣故，今日得以快速成就無上正等正覺，這是重點。我們得探討「知恩報恩」的意涵，能「知恩」，是說能夠明白、瞭解有恩惠的施者與受者；自己有從他處受得恩惠，是接受者。此處的施者就是父母，父母是一切有情出生在三界的最直接因緣，也是最親近的眷屬。

我們如果觀察周遭熟悉的有情，天空飛翔的鳥禽類，水中的海棲類，陸地的雞鴨、虎狼獅子等，以及爬蟲類動物，牠們的智慧足以瞭解恩義之道嗎？更別說低下的病毒細菌、昆蟲螞蟻之類了。單說稱作萬物之靈的人類，有誰會記得自己出生以後，無所能為，完全仰賴他人，最早的一千個日子，如何受父母家人的百般呵護？雖然上學受教育以後，熏習忠孝節義，然而真正能從內心流注「知恩」情義的，有多少人？大部分人都是理所當然領受恩德，因為得來太容易呀！

如果我們不能知恩，何以談報恩呢？想想在家裡日常生活裡父母的關懷：「加一點衣服啊，天氣冷啦！冰水不要喝太多，不要空腹啦！小心喔！小心喔！外面過馬路。」知道啦！知道啦！把門一關——砰！就走了。我們有沒有作這樣的事呢？理所當然我們認為父母從小嘀咕到大，我們都懂的事還一直再三、再三地說，就衝出口！可是父母聽了，晚上下班回來、下課回來，父母會給我們壞臉色嗎？沒有。父母還是一樣：累不累呀？要不要喝點東西？晚餐好了。我們知恩嗎？不是只有這一世喔，我們每個人不僅僅這一世需要受照護，而是無始劫以來的無量世，都是受父母照護。

各位菩薩！我們說明到此，下一集再繼續和大家分享。

敬祝大家：色身康泰、福慧增長！

阿彌陀佛！
